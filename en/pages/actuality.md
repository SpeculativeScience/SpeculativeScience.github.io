# Actuality

## Contingency

```
Inner ⟲ Outer 

Possibility ( Inner ⟲ ~~Outer~~ )

Contingency ( ~~Inner~~ ⟲ Outer )

Condition ( Possibility ( Inner ⟲ Outer ) )
```

Actuality is the immediate unity of Inner and Outer, the thought (Inner) of a concept that subsumes and reflects its presence (Outer) in the world. The Inner and Outer are immediately unified because they were shown to be identical in Content. The Force distinguished from its Expression is reflection-into-itself, or Inner, whereas Expression distinguished from its Force is reflection-into-another, or Outer. Since Actuality is the unity of Inner and Outer, Actuality is the Force that has the Inner and Outer as *its* Expression. When Actuality is distinguished from its Inner and Outer, it becomes Possibility, or the Inner of the Inner and Outer. 

Since Possibility is Inner Actuality, then what is Possible is only a reflection of what is Actual. What is Actual is Possible, but what is Possible may or may not be Actual. Possibility implies the mediation of a thought (Inner) with its negation. If a thought is a Possibility, then its negation is also a Possibility. Moreover, the negation of this thought may or may not imply other Possibilities have their own negations as Possibilities.

What is Possible is not contradictory and has is a reflection of what is Actual. However, Possibility always implies other Possibilities. and since what is Actual only reflects the content of one Possibility, then all other Possibilities are now Impossible. Only one Possibility can be realized, but each Possibility is the same, so the one that is realized is a matter of chance. This is Contingency, or the Outer of the Inner and Outer.

## External Necessity

```
Condition ⇄ ( Possibility ( Inner ⟲ Outer ) )

Conditions ( Possibility ( Inner ⟲ Outer ) )

Fact ( Conditions ( Possibility ( Inner ⟲ Outer ) ) )

Fact ⇄ ( Conditions ( Possibility ( Inner ⟲ Outer ) ) )

Necessity ( Conditions ( Possibility ( Inner ⟲ Outer ) ) )
```

A Condition can only be a Condition if it is Possible and a Possibility can only be a Possibility if it is a Condition. A Condition is Possible only if it implies another Condition, which for that Condition to be Possible, implies another Condition, and so on. This process taken together as a whole is the Totality of Conditions, or the Conditions for short. The Totality of Conditions are the Conditions *for* something, which is the Fact Itself. 

The Conditions generate the Fact Itself because there is nothing left for the Conditions to condition if it is a totality, the Fact Itself is what is unconditioned because it subsumes all of its Conditions. The Fact Itself determines what is Possible, which are determined through Conditions that generate the Fact Itself. Because the Fact Itself begins and ends with itself, it is Necessity. 

## Freedom

```
Substance ( Accidentality ( Possibility ( Inner ⟲ Outer ) ) )

Substance → ( Accidentality ( Possibility ( Inner ⟲ Outer ) ) )

Cause → ( Effect ( Possibility ( Inner ⟲ Outer ) ) )

Cause ⇄ ( Effect ( Possibility ( Inner ⟲ Outer ) ) )

One Cause ⟲ ( Effects ( Possibility ( Inner ⟲ Outer ) ) )

Concept ( Effects ( Possibility ( Inner ⟲ Outer ) ) )
```

Necessity is necessary because it determines itself in and through determining what it includes. What Necessity includes, however, are its Conditions that reflect the content of the Possibilities it determines. Whether this or that Possibility becomes a Condition is a contingent matter, but once it is a Condition, it becomes necessary to Necessity. This moment of Contingency within the process of Necessity is Accidentiality. A Condition is Accidental because it could have been determined by any Possibility. Furthermore, since Necessity determines what Possible and returns to itself as Necessity through Accidentality, Necessity is the Substance of Accidentality.

Because Substance necessarily produces Accidentiality, Substance is the Cause of Accidentality and Accidentality is the Effect of Substance. The Cause causes the Effect and is determined as the Cause by causing the Effect. However, if Cause is determined as a Cause in causing the Effect, then the Effect is the Cause because it causes the Cause. But the Cause is also the Effect because it is caused by the Effect. The Cause that is caused by Effect is Action and the Effect that causes the Cause is Reaction. Reciprocal Action sublates the apparent contradiction of causality by completely systematizing the causal process as the Effects of One Cause. The One Cause initiates the process of Reciprocal Action, but the One Cause is effected by the Effects it generates from this process because it determines and is determined by what it causes. As the cause and effect of itself, the One Cause is the free, self-determining thought - it is the Concept.
