## Judgment

```
Universal ⟹ U

Particular ⟹ is

Individual ⟹ I

Judgments of Inherence

	Positive Judgment: I1 is U1

	Negative Judgment: I1 is not U1 ⟹ I1 is U2

	Infinite Judgment: I is U ⟺ I is not U

		Negative Infinite Judgment:  I1 is not U1 ⟹ I1 is not U2 ⟹ ...

		Positive Infinite Judgment: I1 is I1

Judgements of Reflection

	Singular Judgment: This I is U

	Particular Judgement: Some I’s are U ⟺ Some I’s are not U

	Universal Judgment: All I’s are U

All I’s ⟹ Species

U ⟹ Genus

Judgments of Necessity

	Categorical Judgment: Species is Genus

	Hypothetical Judgment: Species is a Genus ⟺ Genus is a Species

	Disjunctive Judgment: Genus is Species^T^

Genus ⟹ I

SpeciesT ⟹ U-P

Judgment of the Concept

	Assertoric Judgment: This I is U-P.

	Problematic Judgment: This I is not U-P.

	Apodictic Judgment: This I, given P, is U.

This I, given P, is U ⟹ I → P → U
```

## Syllogism

```
Syllogisms of Inherence

	First Figure: I → P → U

	Second Figure: P → I → U

	Third Figure: I → U → P

Syllogisms of Reflection

	Allness: I → P(I, U) → U

	Induction: U → I(P, U) → P(I, U)

	Analogy: P(I, U) → U(I, P) → I(P, U)

Syllogisms of Necessity
	
	Categorical:  I(P, U) → P(I, U) → U(I, P) ⇒ A → B → C

	Hypothetical:  A → B → C → A

	Disjunctive: (A → B → C → A) → (A → B → C)
```
